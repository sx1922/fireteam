# 044 · 游戏循环、PvE/PvP 与按键审计修复

日期：2026-08-28

## 修复清单

### ① 防止启动阶段重复进入 WARMUP

`SETTING_LOADED` 已在启动引导阶段进入 WARMUP 时，`InitPostEntity` 的延迟启动不再重复重置回合编号和计时；仅在状态仍为 IDLE 时启动。

### ② PvP 单阵营保护

ACTIVE 前检查参战阵营数量。PvP 少于两个阵营时跳过本回合并进入幕间，避免单阵营歼灭/占区回合进入无意义战斗。

### ③ 按键备份安全降级

无法由输入 API 解析键码时，备份写入 `<unknown>` 标记；还原时跳过该条目，避免把未知的原绑定误判为空绑定并错误执行 unbind。
